# TTS Supertonic 3

Kotlin Multiplatform on-device text-to-speech SDK powered by [Supertone supertonic-3](https://huggingface.co/Supertone/supertonic-3) and ONNX Runtime. Runs entirely on-device with no network calls at inference time.

Targets: **Android** (API 26+) · **iOS** (16+)

## Project Structure

```
tts-supertonic-3/
  library/          KMP library — shared API, engine, and platform implementations
    commonMain/       Shared TTS API, config, callbacks, text preprocessing
    androidMain/      ONNX Runtime Android inference + AudioTrack playback
    iosMain/          ONNX Runtime iOS inference via Kotlin/Native cinterop
  sample/           Compose Multiplatform sample app (shared UI)
    commonMain/       Shared Compose UI
    androidMain/      Android entry point
    iosMain/          iOS entry point (MainViewController)
  tts-model-pack/   Android asset module for bundled model files
  iosApp/           iOS app shell (Xcode project via xcodegen)
```

## Prerequisites

- JDK 21 (e.g. `brew install openjdk@21`)
- Android Studio (for Android builds)
- Xcode 16+ with command-line tools (for iOS builds)
- [xcodegen](https://github.com/yonaskolb/XcodeGen): `brew install xcodegen`
- [CocoaPods](https://cocoapods.org/) (for building the library's ONNX Runtime cinterop bindings — **not** needed by consumers)

## Getting Started

After cloning, set up your environment and run the one-time setup script:

### 1. Environment

Make sure JDK 21 and the Android SDK are on your PATH. On macOS with Homebrew:

```bash
brew install openjdk@21
```

Add to your shell profile (`~/.zshrc` or `~/.bashrc`):

```bash
export JAVA_HOME="$(brew --prefix openjdk@21)/libexec/openjdk.jdk/Contents/Home"
export ANDROID_HOME="$HOME/Library/Android/sdk"
export PATH="$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$PATH"
```

Then reload your shell (`source ~/.zshrc`) or open a new terminal.

### 2. Run setup

```bash
./setup.sh
```

This does three things:

1. **Creates `gradle.properties`** with required build settings (`android.useAndroidX=true`,
   JVM heap size). This file is gitignored because it can also hold Maven Central publishing
   credentials — edit it later if you need to publish.
2. **Downloads model files** (~400 MB) from
   [HuggingFace](https://huggingface.co/Supertone/supertonic-3) into both the iOS and Android
   asset directories. The model is licensed under
   [OpenRAIL-M](https://huggingface.co/Supertone/supertonic-3/blob/main/LICENSE).
3. **Generates the Xcode project** via xcodegen (if installed).

After setup you should have model files in both locations:

```
iosApp/Supertone_supertonic-3/
  ├── duration_predictor.onnx    (1.5 MB)
  ├── text_encoder.onnx          (27 MB)
  ├── vector_estimator.onnx      (127 MB)
  ├── vocoder.onnx               (97 MB)
  ├── tts.json
  ├── unicode_indexer.json
  └── F1–F5.json, M1–M5.json    (voice styles)

tts-model-pack/src/main/assets/tts_models/Supertone_supertonic-3/
  └── (same files, copied for Android asset bundling)
```

### 3. Build and run — Android

**Android Studio:**

1. Open the project root in Android Studio.
2. Wait for Gradle sync to complete.
3. Select the `sample` run configuration.
4. Run on a device or emulator (API 26+).

**Command line:**

```bash
./gradlew :sample:assembleDebug
adb install -r sample/build/outputs/apk/debug/sample-debug.apk
adb shell am start -n com.nate.tts.sample/.MainActivity
```

The sample app extracts the bundled model from assets to internal storage on first launch.

### 4. Build and run — iOS

#### Option A: Command-line build

```bash
# Build the KMP framework
./gradlew :sample:linkDebugFrameworkIosArm64          # device
./gradlew :sample:linkDebugFrameworkIosSimulatorArm64  # simulator

# Build the iOS app
cd iosApp
./build-ios.sh
```

#### Option B: Xcode

```bash
cd iosApp
open TTSSample.xcodeproj   # already generated by setup.sh
```

The Xcode project includes a pre-build script phase that invokes Gradle to compile the KMP framework, so you can just hit Run in Xcode. Make sure JDK 21 is available (the build script uses `/usr/libexec/java_home -v 21`).

The model directory `iosApp/Supertone_supertonic-3/` is included as a resource folder in the Xcode project automatically.

## Library API

```kotlin
val sdk = TtsSdk(TtsConfig(
    modelDir = "/path/to/Supertone_supertonic-3",
    defaultVoiceStyle = "M2",
))
sdk.initialize()

sdk.setCallback(ttsCallback {
    onStart { id -> println("Started: $id") }
    onDone  { id -> println("Done: $id") }
    onError { id, err -> println("Error: $err") }
})

sdk.speak("Hello, world!")
sdk.speak(SpeakRequest(text = "Bonjour", voiceStyle = "F1", language = "fr"))
sdk.stop()
sdk.shutdown()
```

### Android — Bundled Model Loading

```kotlin
// In Application.onCreate():
AndroidContextHolder.set(this)

// Then at runtime:
val modelPath = getBundledModelPath("Supertone/supertonic-3")
val sdk = TtsSdk(TtsConfig(modelDir = modelPath!!))
sdk.initialize()
```

## Supported Languages

31 languages, listed in
[`SupportedLanguages`](library/src/commonMain/kotlin/com/nate/tts/config/SupportedLanguages.kt) —
the single source of truth shared by both engines and the sample app. The code is
wrapped around the input text as a tag (`<fr>Bonjour.</fr>`) before tokenisation, so
it must match a tag the model was trained on; unrecognised codes fall back to `en`.
